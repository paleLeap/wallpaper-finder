Wallpaper Finder

It searches several wallpaper sites at once and shows you small, cheap previews — a preview costs about 20 KB against 4 MB for the real thing, so you can look at a hundred for the price of one.

Choose Images or GIFs, pick your sources and themes, set a minimum size and a main colour if you want them, and say how many to find. Tick the ones you like and press Submit selections: only those are downloaded at full size, into a folder it asks you about.

It remembers everything it has shown you, so it stops repeating itself, and it skips anything already in your folder. It saves wallpapers — it does not set them.
